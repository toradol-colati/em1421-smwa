Overview 
▶ These examples illustrate potential types of analyses that can be conducted. 
▶ They are not meant to be replicated but serve as inspiration for developing unique and creative projects. 
▶ Projects should align with the course framework and apply the analytical skills covered in class. 
▶ All project proposals must be original and independent. Please refer to the guidelines and instructions available on Moodle.
Example #1 
Analyze public opinions on nuclear energy, identifying prevalent trends, sentiments, and viewpoints on the topic. 
▶ Data: Twitter 
▶ Methodology: Text and sentiment analysis, topic modeling, network analysis
Example #2 
Analysis of the subreddit r/wallstreetbets, which drove up the price of GameStop shares and caused massive losses for hedge funds. 
▶ Data:Reddit 
▶ Methodology: Social network analysis
Example #3 
Investigating the most rewarding behaviour and the social network dynamics within the forum Staker News. 
▶ Data: Staker News 
▶ Methodology: Data analysis, network analysis
Example #4 
Analysis of Taylor Swift’s discography to identify stylistic shifts and thematic patterns. 
▶ Data: Spotify 
▶ Methodology: Data analysis, text analysis, network analysis
Example #5 
Studying patterns of book purchasing on Amazon. 
▶ Data: Amazon 
▶ Methodology: Data analysis, network analysis
