# Project documentation

This directory keeps only material needed to understand and assess the project:

- `EM1421_group_project_brief.pdf`: submitted project proposal.
- `EM1421_projectsInstructions.txt`: official project requirements.
- `writing_your_project.txt`: instructor's report-quality guidance.
- `DATA.md`: final data preparation, validation and limitations.
- `code_evidence_map.md`: mapping between code sections, course concepts and
  project-specific extensions.

Course slides, exam-preparation material and internal working notes are kept on
the `archive/course-and-working-notes` branch. They are not part of the project
deliverable on `main`.
